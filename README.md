# DevTech Academy - Gerenciamento de Alunos

Sistema CRUD de alunos em HTML, JavaScript e Bootstrap.

# Funcionalidades
- Cadastro, edição e exclusão de alunos
- Classe `Aluno` com `isAprovado()` e `toString()`
- Eventos com `addEventListener`, funções anônimas e arrow functions
- Relatórios: aprovados, médias, ordem alfabética e alunos por curso

# Como executar (Docker)
    docker compose up -d --build
Acesse http://localhost:8080

# Para parar
    docker compose down
